# LineDrawingGDI

Just a sandbox for line drawing with GDI.

## Features

- **Three-module design**: Includes an orbital module, a descent module, and a service module.
- **Crew capacity**: Accommodates up to three astronauts.
- **Compatibility**: Designed to dock with the International Space Station (ISS) and other spacecraft.
- **Launch escape system**: Provides emergency crew safety during launch.
- **Orbital module**: Contains living and storage space for crew during flight.
- **Descent module**: Houses the crew during re-entry and landing, equipped with heat shields for protection.
- **Service module**: Contains engines, fuel, and life support systems.
- **Autonomous operation**: Capable of automated docking and flight control with manual override options.
- **Reliable parachute landing system**: Uses parachutes and retro rockets for a soft landing.
- **Proven durability**: Operates in a variety of missions, with a long record of reliability since the 1960s.
